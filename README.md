# Auto Ledger

仅供本人 Android 手机使用的离线自动记账工具。

## 核心目标

监听微信、支付宝、云闪付、农行和招商银行的交易通知，在手机本地生成账目，并通过商户记忆和关键词规则离线分类。通知信息不足时进入待确认，不猜测入账。

## 隐私承诺

- 应用不申请网络权限。
- 不连接服务器，不使用云同步、广告、统计或在线 AI。
- 账本只保存在手机应用内部。
- 不读取短信。
- 微信只读无障碍仅在用户主动开始一次采集后读取当前可见文字，不点击、不输入、不滚动。
- 无障碍读取不到文字时，可由用户主动授权截取一帧；截图只在内存中交给随 APK 分发的本地 OCR，识别完成立即销毁。
- Android 云备份和数据迁移将被显式关闭。

## 当前状态

已创建 Android 16 / API 36 的最小 Kotlin + Jetpack Compose 工程，并完成：

- 本月收入、支出和待处理数量
- 最近账目列表
- 账目、图表和手动记账三个入口
- 通知访问授权入口
- 仅针对微信的单次通知样本采集
- 仅 Debug 版可见的固定虚构付款通知样本
- 虚构通知的整数“分”解析、Room 唯一指纹去重、待确认编辑和确认
- Room v1 本地账目持久化，应用进程结束后仍保留
- 微信没有系统通知时的单次只读界面样本采集
- 用户主动授权的单帧屏幕捕获和离线中文 OCR
- 原始通知、界面文字和 OCR 样本只保存在进程内存中；通知采集一条后停止，界面采集切回应用后停止

账目页面从本地 Room 数据库显示待确认和已确认账目。解析器只覆盖固定虚构样本验证过的格式；自动分类和导出尚未实现，在取得真实交易通知样本前不扩展猜测分支。

微信账单页实际使用的 WebView 不暴露可访问文字，因此只读无障碍入口继续保留；无通知场景改用用户主动、单次屏幕捕获和纯本地 OCR。OCR 取得真实样本前只展示候选，不猜测格式或静默入账。

## 采集微信交易通知样本

1. 首页点击“设置”。
2. 点击“打开通知访问设置”，开启“Auto Ledger 通知采集”。
3. 返回应用，点击“采集下一条微信通知”。
4. 立即完成一笔微信交易，等待通知出现。
5. 返回采集页面查看 `title`、`text`、`bigText`、`subText` 和 `textLines`。

采集器只接受 `com.tencent.mm` 的下一条通知（包括群组汇总），不持续保存原始通知。普通微信消息也可能被捕获，必要时清除后重新采集。

## 使用模拟数据测试

1. 首页点击“设置”。
2. 点击“模拟微信付款通知”；Debug 模拟不要求通知访问权限。
4. 页面会显示固定虚构样本：测试商户、￥12.34。
5. 点击“返回”，首页支出、待处理数量和最近账目会同步显示该样本。
6. 点击“处理待确认”，可修改金额、对象和分类，再点击“确认入账”。
7. 连续生成相同样本不会产生重复候选。

该入口只在 Debug 版显示，直接复用单次内存采集入口，不发布系统通知，也不持久化原始通知；解析后的固定虚构账目会写入 Room。它用于验证样本进入应用后的持久化流程，不能证明真实微信通知一定包含金额。

## 采集微信交易页面样本

1. 首页点击“设置”，在系统无障碍设置中开启“Auto Ledger 微信只读采集”。
2. 返回应用，点击“开始并打开微信”。
3. 完成交易并停留在交易结果页。
4. 不要在微信内返回，直接从最近任务切回 Auto Ledger。

服务在 XML 和代码中均限制为 `com.tencent.mm`，不声明手势、按键过滤、触摸探索或截图能力。页面原始文字只保存在进程内存中。

## 单次 OCR 采集

1. 在微信支付结果或账单详情页停留。
2. 从最近任务切回 Auto Ledger，进入“设置”。
3. 点击“截取当前微信页面”，同意 Android 的单次屏幕共享提示。
4. 应用切回微信并只截取一帧，本地 OCR 完成后立即释放截图和投屏会话。
5. 返回 Auto Ledger 查看识别结果；确认前不会生成正式账目。

OCR 使用随 APK 分发的 Tesseract 简体中文模型，不下载模型，不上传截图、识别文字或运行指标。

## 本机构建

已安装 Android Studio Quail 2、Android SDK 36 和 Platform Tools。

```powershell
$env:JAVA_HOME='C:\Program Files\Android\Android Studio\jbr'
.\gradlew.bat :app:assembleDebug --no-daemon --console=plain
.\gradlew.bat :app:testDebugUnitTest :app:lintDebug --no-daemon --console=plain
```

Debug APK：`app\build\outputs\apk\debug\app-debug.apk`
